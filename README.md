# Atividade Prática #1 – APIs RESTful

## Como correr a API simulada (Partes 1–3)
```bash
cd mock-server
npm install
npm start
```
- API: http://localhost:3000/alunos e http://localhost:3000/cursos
- Front-end: http://localhost:3000 (servido pelo json-server)
